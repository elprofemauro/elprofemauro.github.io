## 🌌 Mi filosofía

Creo que la educación no tiene por qué estar separada de la tecnología.

Una idea puede convertirse en:

**🧠 concepto → 🔬 experimento → 💻 código → 🎨 visualización → 🎮 experiencia**

Y ahí es donde comienza la diversión.
